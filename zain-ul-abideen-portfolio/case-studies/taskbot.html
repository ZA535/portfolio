TaskBot

A Slack-native task accountability app built under Apsis Grid — assign work where teams already communicate, track completion in real time, and automate reminders without adding another dashboard.

Role: Founder & Full Stack Engineer Platform: Slack Status: Production (LIVE)
Visit Apsis Grid ↗ Work with me
01 — Problem

Tasks get lost in chat

Teams run on Slack, but assignments often disappear in threads. Managers chase status updates manually, and separate task tools create context switching. The goal was calmer operations: one clear view of what moves next, inside the workspace people already use daily.

02 — Solution

From assignment to done — inside Slack

Broadcast with intent

Assign a clear task to everyone or a selected group in a few focused steps — no noisy broadcasts.

See real progress

Understand who is done and where attention is needed without chasing teammates for updates.

Nudge at the right time

Automatic deadline reminders keep work moving without manual follow-up.

03 — Product principles

How TaskBot is designed

  • Clear by default — Every workflow earns its place; no feature clutter.
  • Human at heart — Familiar Slack patterns and immediate value on day one.
  • Built to endure — Security and reliability treated as infrastructure, not extras.

High-level flow

  1. Manager creates a task broadcast in Slack (team or subset).
  2. TaskBot delivers interactive messages; teammates mark completion in-channel.
  3. Progress aggregates for visibility; reminders fire before deadlines.
  4. Deployments ship via GitHub Actions to VPS with rollback-friendly process.
